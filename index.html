Every leaf, counted and outlined.

LeafVision uses a deep Mask R-CNN instance segmentation model to detect, classify, and generate pixel-level masks for each individual leaf in complex crop canopies — enabling high-throughput automated plant phenotyping.

  • Architecture

    Mask R-CNN

  • Backbone

    ResNet-50 FPN

  • Task

    Instance Seg.

  • Target Class

    Leaf

  • Output

    Masks + Boxes

  • API Endpoint

    /api/segment

02 / Pipeline

From pixels to leaf instances

What happens between pressing Segment Leaves and seeing the output.

  1. 01 IN

    Image Upload

    Plant image is validated in browser and sent as multipart form data.

  2. 02 PRE

    Preprocessing

    The backend applies Excess Green index and normalises to model format.

  3. 03 RPN

    Region Proposals

    The FPN backbone and RPN propose candidate regions containing leaves.

  4. 04 MASK

    Mask Prediction

    Each region is classified, refined, and given a pixel-level leaf mask.

  5. 05 OUT

    Overlay & Count

    Masks are rendered as distinct colour overlays with instance metadata.

Model Specification

Architecture Mask R-CNN (two-stage instance segmentation)
Backbone ResNet-50 with Feature Pyramid Network (FPN)
Prediction Heads Box classification, box regression, per-instance mask
Target Class Leaf (single foreground class)
Serving API FastAPI · POST /api/segment-batch

Leaf Counting

Automatic per-plant leaf counts for growth rate and developmental tracking.

Phenotyping

Per-leaf masks enable precise surface area (LAI), shape, and perimeter analysis.

Health Screening

Isolated individual leaves can be passed to downstream pathology models.
